# Changelog

## 1.0.0

- First release: favicons, app icons, a maskable icon, `site.webmanifest` and
  a share image from a website's logo files and a JSON config, rendered by the
  system's Chrome, Chromium or Edge. Install it with `npm i -D web-brand-assets`
  or run it with `npx web-brand-assets CONFIG`.
- A Node.js API, `generate(configPath, options)`, exported from the package.
- Requires Node.js 20 or later; no runtime dependencies.
